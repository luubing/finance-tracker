**实现要点 / 发现**

1. **MASA 的 Transition 脚本会被 SVG 过渡事件弄出 `TypeError`**：进度环的弧（SVG `<circle>`）有 `stroke-dasharray` 过渡，`transitionend` 冒泡到页面上任何 MASA `Transition` 宿主，`masa.blazor/1.11.9/.../transition/index-*.js` 读 `e.target.className.split(" ")`，而 SVG 元素的 `className` 是 `SVGAnimatedString`，于是每次弧长变化都抛一次页面异常（功能没坏，但控制台 / `pageerror` 被污染，E2E 的 `check_clean` 才发现）。修法：`ui.js` 在文档**捕获阶段**对目标是 `SVGElement` 的 `transitionend` / `transitioncancel` 调 `stopPropagation()`——这类事件没有任何人需要处理，拦在最外层，MASA 就读不到。
2. **「整行可点」的伪元素要显式 `z-index`**：名称按钮的 `::after` 铺满整行，但进度条（`ProgressBar`）也是定位元素，同为 `z-index: auto` 时后出现的进度条在上，点进度条那 6px 点不到按钮。`.ft-budgetrow__open::after` 加 `z-index: 1` 后整行（含进度条）都是点击区域，按下底色也均匀铺满（E2E `covers_row` 用 `elementFromPoint` 在进度条 / 左 / 右 / 名称四个位置核对）。
3. **写库也要排进 `PageDataGate`**：Tab 根页面常驻、可能正在刷新，它们与二级页共用同一个 scoped `DbContext`；`PageDataGate` 是单车道信号量（不可重入），所以保存 / 删除与读一起排队，别在 `RunAsync` 里再嵌套 `RunAsync`。
4. **环里的数字要和状态同口径**：`UsagePercentage` 是服务层 `Math.Round(used / amount * 100, 1)`（decimal 默认银行家舍入），页面显示再向下取整；状态判定（≥ 80% / ≥ 100%）用「显示的百分比」，所以 79.96% 显示 79% 仍是「正常」、99.9% 显示 99% 还没「超支」；E2E 的 `shown_percent` 用 `ROUND_HALF_EVEN` 镜像这套规则。
5. **E2E 造数要把「全部账本的总预算统计全部账本的支出」算进去**：造「接近上限」场景时，别的账本里的账单也计入全部账本的总预算（第一版把 10000 的总预算配了 17913.5 的支出，变成了超支）。
6. **进度环弧长是 500ms 过渡**：读 `stroke-dasharray` 的几何断言前必须 `wait_animations_settled`；减少动态效果下 `transition-duration` 是 `0s`（E2E K 节）。
7. **窄屏 320**：总览卡 < 360px 改成上下排（环居中），筛选行折行（账本胶囊放到月份胶囊下面），八位数金额 ≥ 12 个字符缩小一档字号、极端长的已用 / 剩余金额折到下一行右对齐，整张卡没有元素冲出（E2E J 节逐元素核对）。
8. **「日均可用」按应用时区的今天算**：E2E 用运行机器的 `datetime.now()` 推算期望值（应用时区默认 = 本地时区），跨午夜的极端情况会差一天；时区边界本身由 `BudgetPagePresentationTests` 在 UTC+8 / UTC-5 下锁定。
