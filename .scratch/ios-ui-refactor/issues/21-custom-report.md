## 实现说明

- 覆盖 spec 用户故事：54、92。
- 设计稿：07 · 逐页改动清单中 `/custom-report` 一行（保留为推入页，入口改到统计右上角）。**设计稿没有自定义报表的专属画面**（screens 的 13 张里没有），视觉按二级页面模板 + 设置式分组列表（`GroupedList` / `ListCell`，与短信识别 / 导入同一套）+ 统计 Tab 的卡片与图表。

**实现要点 / 发现**

1. **点「生成报表」后，「生成中」这一帧永远渲染不出来**：本地 SQLite 的异步查询常常同步完成，`_loading = true; StateHasChanged(); await 查询` 里的 `await` 根本没有让出，渲染队列来不及把「生成中」画出去，用户只看到按钮没反应、也没有骨架。单元测试（纯函数）与读代码都看不出来，是 E2E 用 `MutationObserver` 抓「`data-state="loading"` 是否曾经出现」才暴露的。修法：`StateHasChanged()` 之后 `await Task.Yield()` 让渲染先走，再查询。根节点的 `data-generation`（已结束的生成次数，成功 / 失败各算一次）让测试等「这一次生成结束」，不靠固定延时。
2. **统计服务的一个旧缺陷**：`GetCategoryComparisonAsync` 在本期没有这个分类的账单（本期归零）时，名称与图标取的是本期的数据，于是显示成「未知分类」；现在回退到上一周期里它自己的名称与图标。`CustomReportStatisticsTests` 锁定（金额 / 排序 / 变化率不变）。
3. **旧页「今天」用 `DateTime.Now`**：运行环境时区与应用时区不一致时会差一天（ADR 0005）；现在取 `AppTimeZone.ToLocal(DateTime.UtcNow).Date`。
4. **旧页导出 / 分享的三处缺陷**（CSV 金额带千分位、分类名不转义、用户取消分享仍写剪贴板）一并修了，见判断 5。导出改用 Blob + 隐藏 `a[download]`，不再 `eval` 拼 data URI。
5. **320pt 窄屏上位数多的 KPI 金额挤出栏**：`¥98,765,432.10`（14 个字符）在原有的 14px 下 104.5pt，比 96pt 的栏还宽。E2E G 节逐元素量宽度才发现；新增 `xlong` 字号档（12px，仅 `< 360pt` 的屏）。`KpiCard` 是共享件，统计 Tab / 导入页同样受益。
6. **MASA Snackbar 会盖住页面底部的行**：导出 / 分享后的「报表已导出」提示压在最后一行上，下一次点击被拦截；固定在底部的主按钮栏同理。E2E 里点底部行之前要等 Snackbar 消失并滚到视口中间。
7. **`voice_overlay_test.py` 的一个偶发失败（与本 ticket 无关）**：全量回归时「取消区整层泛红」读到了 `rgba(99, 26, 43, 0.796)`（目标 `rgba(110, 24, 32, 0.8)`）——背景色过渡从「改属性后的第一次样式重算」才开始计时，机器忙、首帧晚了几十毫秒时，固定的 280ms 睡眠结束时过渡还差一截。改成 `el.getAnimations()`（先刷新样式让过渡立刻建立）+ `finished` 等过渡真正走完，单独复跑 109/109。
8. **`.ft-form-error` 的颜色是 `--ft-expense`（白底 4.2:1，不到 4.5:1）**：报表页的校验提示用它，一并改成 `--ft-danger-text`（≥ 5:1），`DesignTokensTests` 与报表 E2E 的 B 节都锁定了。
9. **旧的 `LedgerSelect`（MASA 下拉）至此已经没有调用方**（旧报表是最后一个用它的页面），留给 24 号收尾时删除。**（24 号已删除）**。
10. 回归：`dotnet build FinanceTracker.sln` 0 警告 0 错误；`dotnet test` 1863 个用例全部通过；`run_all.py` 24 个脚本、共 2664 项检查（base-selftest 186、addbill-sheet 174、bills-page 277、smoke 7、budgets-page 129、categories-page 133、custom-report-page 145、edit-bill-sheet 104、home-page 94、immersive-safe-area 31、import-page 166、ledger-members-page 138、ledgers-page 147、login-addbill 7、payment-channels-page 106、pending-bills-page 182、profile-page 97、seed-visibility 9、statistics-page 114、statistics-trend-annual 157、tab-shell 64、tab-slider 82、voice-addbill 6、voice-overlay 109）。其中全量回归当次 23/24 通过（`voice-overlay` 偶发 1 项，见第 7 条），该脚本修复后单独复跑 109/109；报表脚本在全量回归之后新增 1 项（B 节的错误提示颜色），单独复跑 145/145（全量回归当次是 144）。最终的全量回归在 24 号再跑一遍。
