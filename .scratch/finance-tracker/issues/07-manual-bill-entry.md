# 07 — 手动记账

**What to build:** 用户可以创建一笔账单（支出或收入），选择分类、支付渠道、输入金额、选择交易时间、填写备注。创建成功后显示在账单列表中。

**Blocked by:** 05 — 分类管理, 06 — 支付渠道管理

**Status:** completed

- [x] 支出/收入类型切换
- [x] 金额输入组件（数字键盘）
- [x] 分类选择组件（网格展示）
- [x] 支付渠道选择组件
- [x] 日期时间选择器
- [x] 备注输入框（可选）
- [x] 表单验证
