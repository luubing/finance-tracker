# 用户认证方案

采用手机号手动输入方式，无复杂登录流程。

## 认证方式
- **标识方式**: 手机号作为唯一标识
- **登录流程**: 手动输入手机号，无需验证码/一键授权
- **会话管理**: 本地存储用户标识，支持"记住登录状态"

## 考虑的替代方案
- 短信验证码: 需要短信服务，有成本
- 运营商一键登录: 需要企业资质，实现复杂
- 微信授权登录: 依赖第三方平台

## 设计决策
- 不采用复杂认证流程，降低用户使用门槛
- 手机号作为唯一标识，简化用户管理
- 后续可根据需要增加验证码等安全措施

## 公开部署时的补充
手机号即身份意味着：云端地址一旦公开，任何人都能用任意手机号注册并登录。公开前的取舍与可选的缓解措施
（云端地址构建时注入、API 层的手机号白名单）见 [ADR 0009](0009-cloud-access-hardening.md)，已知的安全边界见仓库根目录的 [SECURITY.md](../../SECURITY.md)。
