# 技术栈选择

采用 .NET MAUI Blazor 作为移动端框架，ASP.NET Core + PostgreSQL 作为后端。

## 移动端
- **框架**: .NET MAUI Blazor (跨平台 Android/iOS)
- **UI库**: MASA Blazor (Material Design风格)
- **本地数据库**: SQLite (轻量、跨平台)

## 后端
- **框架**: ASP.NET Core Web API
- **ORM**: Entity Framework Core
- **数据库**: PostgreSQL
- **API风格**: REST

## 考虑的替代方案
- Flutter/React Native: 团队更熟悉 .NET 生态
- MySQL/SQL Server: PostgreSQL 功能更强大且免费
- GraphQL/gRPC: REST 更简单，团队更熟悉
