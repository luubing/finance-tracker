# 数据同步策略

采用实时同步模式，冲突处理采用"后写入优先"策略。

## 同步模式
- **实时同步**: 每次操作立即上传到云端
- **离线支持**: 无网络时本地操作，联网后自动同步
- **同步上限**: 离线最多缓存1000条记录

## 冲突处理
- **策略**: 后写入优先 (Last Write Wins)
- **实现**: 基于时间戳，最后修改的版本覆盖之前的版本
- **删除**: 采用软删除，同步时传递删除标记

## 考虑的替代方案
- 延迟同步/定时同步: 用户体验不如实时同步
- 版本向量/CRDT: 实现复杂度高，对于记账场景不需要
- 物理删除: 无法同步删除操作，可能导致数据不一致
